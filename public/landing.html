🚀 Quick Start

Up and Running in 4 Steps

From sign-up to sending your first WhatsApp message — no complex setup, no delays.

1

Create an Account

Register with your email. Get a free 7-day trial instantly with 3 device slots and 100 messages/day.

2

Add a Device

Enter your WhatsApp phone number, scan the QR code from your dashboard, and your device is live.

3

Generate API Key

Create your 32-character hex API key from the API section and use it in any HTTP client or code.

4

Send Messages

Hit our REST endpoints with your API key, device ID, and message. WhatsApp delivered in seconds.

Integrate in Minutes

Simple REST endpoints with query-string parameters — compatible with any language, platform, or legacy system. No complex SDKs required.

POST /auth/register Create account
GET /api/messages/send-text Send text
GET /api/messages/send-pdf Send PDF
GET /api/messages/send-image Send image
POST /device/create Add device
DEL /device/:deviceId Remove device
